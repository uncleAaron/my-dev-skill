# 文档与交付

交付前逐项对照 AC、详细设计、任务、代码、真实测试和使用说明。更新受影响 README、接口说明、部署配置及必要架构决策；不适用项写理由。

补全 test-cases.md 中每个 AC 的可执行测试、输入、期望、造数、隔离、清理、下游模式与命令。知识条目写入 knowledge.json，运行 consolidate-knowledge 更新主题入口；knowledge.md 记录合并/失效/无新增理由。

delivery.md 包含：变更范围、已实现/已验证/未验证/阻塞、实际执行命令与证据时间/指纹、兼容/迁移/回退、剩余事项和恢复入口。自审不得称独立评审；离线脚本样例不得称为 OpenCode 实机验证。

有必需阻塞时输出部分交付，保留问题与解除条件；不能把环境缺失当成测试成功。全部门禁通过后 advance 至 complete，再核对当前 state。是否提交、推送、开 PR、合并或发布取决于用户与项目授权，完成代码并不自动授权生产操作。
